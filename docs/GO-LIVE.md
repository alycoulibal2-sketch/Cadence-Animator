## 2. Prices and payment links — one command

Use the account's **secret** key for this step only (Stripe → Developers → API keys). It creates the
$9 founding price (limited to 100 completed checkouts), the $12 regular price, and two payment links
that send the buyer back to the site's thanks page; run twice and it finds what it made the first time.

```bash
cd services/license
set STRIPE_SECRET_KEY=sk_live_...
set SITE_URL=https://alycoulibal2-sketch.github.io/Cadence-Animator
node tools/setup-stripe.mjs
```

It prints two `plink_…` ids and two `https://buy.stripe.com/…` URLs. Keep them for steps 3 and 4.
(`--dry-run` shows the plan without creating anything.)

## 3. The licence service on Render

Render → New → **Blueprint** → this repository, branch `fix/pnx-status-line-tracks-evaluation`. The root
`render.yaml` describes the service (`services/license`, Node, free plan). In the dashboard fill:

| Variable | Value |
| --- | --- |
| `STRIPE_SECRET_KEY` | a **restricted** key: Checkout Sessions Read, PaymentIntents Read, Charges Read — nothing else |
| `FOUNDING_PAYMENT_LINK` | the founding `plink_…` from step 2 |
| `PRO_PAYMENT_LINK` | the regular `plink_…` from step 2 |
| `ALLOWED_ORIGINS` | `https://alycoulibal2-sketch.github.io` |
| `LICENSE_SECRET` | generated by Render — copy it somewhere safe; every key depends on it |

The service starts even before the key is pasted (it answers "not connected" until then), so the deploy
is green immediately. Note the URL, e.g. `https://cadence-license.onrender.com`. Check
`https://<url>/health` → `{"ok":true,"configured":true}`.

## 4. Switch the site on and publish it

In the site branch (`worktree-agent-a7177df7645eae6c0`, checked out at `.claude/worktrees/agent-a7177df7645eae6c0`),
edit `site/assets/js/config.js`:


Commit it there, then publish the site from that branch:

```bash
cd .claude\worktrees\agent-a7177df7645eae6c0
git add site/assets/js/config.js && git commit -m "Site: Pro is open"
git subtree split --prefix=site -b gh-pages-tmp

git branch -D gh-pages-tmp
```

Live at <https://alycoulibal2-sketch.github.io/Cadence-Animator/> within a minute. Merge the site branch
into the working branch once the other session's `site/` edits are committed
(`git merge worktree-agent-a7177df7645eae6c0`, keep the branch's version of any `site/` conflict).

**Cadence Pro: enter your key** command (Ctrl+K) → `/verify` → the simulation pack and procedural export
switch on. Refund within 14 days: the key stops verifying at the next check.
