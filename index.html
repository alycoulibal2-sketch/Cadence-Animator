A standalone Windows app, not a docked plugin: a real 3D viewport, every Moon Animator 2 keybind, a VFX studio, and two-way sync with Roblox Studio.

Real curve editing

A dope sheet for timing and a bezier curve editor for feel. Thirteen easing styles in four directions, ported from Moon’s own engine and verified bit-exact — quirks included, so animations match.

VFX Studio and a procedural engine

Effects as layers you can keyframe, with a 389-node procedural engine underneath — and the Effect Sheet, which makes any effect without learning nodes. One self-contained Luau script out.

Roblox Studio, and Claude

A one-file companion plugin brings rigs in and sends KeyframeSequences back over 127.0.0.1. And an MCP server with 207 tools lets Claude animate with you — including screenshots, so it checks its own work.

Moon Animator 2 costs $29.99. The Cadence animator is free.

Moon is very good, and Cadence deliberately matches it — the same easing engine, the same keybinds, the same animatable-property registry, the same AnimSaves convention. What changes is where it runs, what it can reach, and what it costs.

What Windows will show you

“Windows protected your PC” is about a signature, not a detection.

The first time you run a new release, SmartScreen shows the blue panel. It appears because the file is not code-signed — Windows cannot name a publisher, so it says Unknown publisher. It has not found anything in the file; Defender still scans it like any other download.

  1. Click More info.
  2. Check that the app name matches the file you downloaded.
  3. Click Run anyway. If you would rather not take our word for it, verify the SHA-256 first.

The honest plan: a code-signing certificate costs about $150–300 a year, which a free app has no budget for. The paid plans will fund it once they open; when releases are signed, the warning goes away for everyone — the free build included. (Windows 11’s optional Smart App Control blocks unsigned apps outright rather than warning; if you have it on, signing is the only fix.)

Questions

What is Cadence AI, and when can I use it?

A helper inside Cadence: you describe a move in plain words, and it builds the animation on your rig from real Roblox clips, then checks it — planted feet, smooth hand-overs. It is being built now and is not in the app yet.

It will arrive as a free update, and the free plan will include 3 AI animations a day. How you’ll hear about it.

Will Cadence AI need the internet?
Yes. It will run on Corvexsa’s own computer as an online service — not a big AI company — so there is nothing extra to download and everyone gets the same speed. Your words are sent to write the plan and then thrown away; your animations stay on your PC. Quick moves, follow-up changes and animating by hand won’t need it, and the animator itself works offline today.
Is it safe?

Yes, and you don’t have to take our word for it: the safety page links every claim to the file that makes it true. In short — the source is public (MIT); the app connects only to your own machine, to Roblox’s asset servers when you load an avatar, to GitHub for update checks, and to Cadence’s licence server if you enter a Pro key; it writes only inside its own %APPDATA% folder and to files you choose; its interface cannot run remote code; and you can hash your download before running it.

The Windows warning you will see is about the missing code signature, not a detection. Here is what it looks like.

Why is the animator free?
Because it should be. Moon Animator went paid in 2023, and a lot of Roblox animators are young and have no card. The animator is MIT-licensed and stays free. The paid plans exist for Cadence AI, which costs real money to run every time someone uses it.
Will it stay free?
Yes. It is MIT: even if Cadence stopped tomorrow, anyone could build and ship it, and that is the point of the licence. The plans add Cadence AI on top; nothing that is free today moves behind a plan.
I bought the old Pro. What happens now?
You’re a Founder: Pro forever, with every future Pro feature included — nothing to renew and nothing to do. Your key keeps working. Check your key.
I don’t have a card.
You don’t need one: the animator is free, with no account. When the paid plans open, a parent can pay — the app will have an Ask a parent button that makes a link for them, so you never type a card or an email. What your parent will see.
Can I use it commercially?
Yes. The animations and effects you make are yours, with no attribution required. The app itself is MIT-licensed, so a studio can use it, modify it and ship it; the only condition is keeping the licence notice with the code.
Do I still need Roblox Studio?
Yes, for two things: getting rigs out of your game and publishing the finished animation. You can animate entirely in Cadence — the built-in R6, R15, Rthro and Rthro Slender rigs need no Studio at all — but Studio is where the export lands and where Roblox’s own Animation Editor turns it into an asset ID.
Is there a macOS or Linux build?
Not today. The published builds are Windows x64 only. The app is Electron, so nothing about it is fundamentally Windows-bound, but no other platform has been built or tested and it would be wrong to imply otherwise.
Will it overwrite my Moon Animator work?
No. Cadence reads and writes the same AnimSaves folders Moon and Roblox’s Animation Editor use, and identifies rigs by a GUID attribute rather than by name, so it cannot mix up two rigs that share a name. Exports go to a name you choose.
How do updates work?
The installed build checks the project’s GitHub releases a few seconds after launch, and whenever you run Check for updates. If there is a newer version a chip appears in the title bar. Nothing downloads or installs until you click it, and a failed background check stays silent rather than interrupting you.
What actually gets sent anywhere?
Roblox’s own servers, for the things that need them: looking up an avatar, fetching a mesh, texture or model asset, and reading a published animation. The update check asks GitHub. If you enter a Pro key, the app checks it with Cadence’s licence server — once, then about once a week. The Studio bridge and the MCP server are loopback-only, and the phone companion is off unless you turn it on. There is no analytics or telemetry of any kind. When Cadence AI launches, your words will go to it to write the plan, and it will not store them. The privacy page is ten lines.
Is it finished?
It is at 0.14.0 and used in real projects, with a smoke test run against the real app before each release. It is also below 1.0 and moving quickly — the changelog shows how quickly. The node editor inside VFX Studio is explicitly early. If something breaks, the app keeps a log next to its settings and the repository takes issues.
