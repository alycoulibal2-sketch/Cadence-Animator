03 Animate

Fix a foot slide in one drag.

Press T, grab the foot, and the knee and hip follow. Then see the frame before and the frame after it, with the keys your hands already know.

Inverse kinematics

Drag a hand or a foot and the joints above it follow. A cyclic-coordinate-descent solver works on the rig’s own motors, with a configurable chain length, and lands its result in the same auto-key and undo pipeline as manual posing.

T

Onion skinning

See where the pose came from and where it is going: ghosts of past frames in blue and future frames in orange, drawn from the same geometry as the live rig, so they cost nothing to show.

N B

Your Moon keybinds, on day one

63 shortcuts matched to Moon Animator 2 on purpose, and a 117-command palette behind Ctrl K for everything else. Muscle memory carries over; nothing to relearn.

Space S A W E

Real curve editing

A dope sheet for timing and a bezier curve editor for feel. Thirteen easing styles in four directions — 52 curves ported from Moon’s own engine and verified bit-exact, including the two quirks Moon has, kept so animations match.

Never lose an animation again

There is no “save before you close”. Every change is on disk within a second, the last ten generations are kept as rolling backups, and reopening the app resumes the project you were in with no dialog to dismiss.

Animate the whole scene

Moon’s animatable-property registry carried across in full: 67 Roblox classes on the timeline, 22 one-shot actions, event markers with their own Luau, keyframed cameras, screen effects, and an audio waveform to time hits against.

04 Effects

Build the effect nobody wrote a preset for.

A second window just for effects: layers you can keyframe, and under them a procedural node engine that exports to Roblox as real ParticleEmitters where it can and as an honest baked recording where it cannot.

VFX Studio

Effects are multi-layer documents — emitter, shape, light, screen, shake, sound — every layer keyframeable, every frame deterministic. Start from 396 particle presets and 25 multi-layer archetypes, or sketch the effect and let Cadence compose it. One self-contained Luau script out.

6 layer types · 8 modifiers

The procedural engine

389 node types across 30 categories — fields, distance fields, geometry, a real particle solver, textures, renderers. There is no “colour over lifetime” setting; you wire age into a gradient, and the same three nodes give you size over distance or emission over speed. Claude edits the same graph you do.

native · converted · baked · refused with a reason
New in 0.11.0

The Effect Sheet: any effect, without learning nodes

The graph stays the engine; you never have to see it. An effect becomes a sheet of things you can see — sparks, a ring, a beam — each with plain-English properties. Every value has a “how does it vary?” menu — fixed, random per particle, over its life, by where it is, noise — with a live thumbnail of this effect under each choice. Drag handles on the stage, edit one ghost particle and get a thousand.

Stated here rather than discovered later: the shipping build (0.11.0) has the grid fluid solver, the volume renderer, flocking, liquid pressure and sub-emission, so simulated fire, smoke and raymarched clouds are real in it. What is still absent: liquids with a free surface, which need a different solver, and GPU compute, so a 64³ simulation is a bake rather than real time. The roadmap says what is ahead. Where a capability is absent, the node for it is absent too.

05 Studio + Claude

Rigs in, animations back. Nothing leaves your PC.

A companion plugin — one readable Lua file — bridges Cadence and Roblox Studio over 127.0.0.1:35747. Cadence installs it for you, and the same local design lets Claude drive the app through an MCP server.

  1. Install the plugin Click the Studio offline chip in Cadence and it writes CadenceBridge.lua into your Roblox plugins folder. Restart Studio, turn on Allow HTTP Requests, and hit Connect on the new toolbar tab.
  2. Pull in any rig Your own Roblox avatar by username, whatever is selected in Studio’s Explorer at any nesting depth, any model by asset ID, or an .rbxm / .rbxmx file. R6, R15, Rthro and Rthro Slender are built in.
  3. Animate, then export Cadence writes a KeyframeSequence into <rig>.AnimSaves.<name> — the same convention Roblox’s own Animation Editor uses, so it opens there ready to publish. Moon exports come in the same way.
One honest limit: no third-party tool can push an animation straight to Roblox’s asset servers. Cadence gets it into the Animation Editor; the final Import → Export click is Roblox’s, not ours.

Let Claude do the animating

139 MCP tools, and it can look.

Cadence ships a Model Context Protocol server: Claude can add a rig, set exact keyframes, solve IK, build a procedural effect, run the quality checker and export to Studio. render_frame hands it a real screenshot of the viewport at any frame, so it checks its own work instead of assuming.

  • It checks its own work. validate_animation flags rotation and position pops, joints that never move, and a dead tail after the last keyframe.
  • One click to connect. Press Claude Control in the title bar and Cadence registers itself with the Claude CLI.
  • Loopback only. The MCP server talks to the running app on 127.0.0.1:35748; nothing about it reaches the internet.

What Windows will show you

“Windows protected your PC” is about a signature, not a detection.

The first time you run a new release, SmartScreen shows the blue panel on the right. It appears because the file is not code-signed — Windows cannot name a publisher, so it says Unknown publisher. It has not found anything in the file; Defender still scans it like any other download.

  1. Click More info.
  2. Check that the app name matches the file you downloaded.
  3. Click Run anyway. If you would rather not take our word for it, verify the SHA-256 first.

The honest plan: a code-signing certificate costs about $150–300 a year for a project like this, which a free app has no budget for. Pro purchases fund it. Once releases are signed, the warning goes away for everyone — the free build included. (Windows 11’s optional Smart App Control blocks unsigned apps outright rather than warning; if you have it on, signing is the only fix, and it is what Pro pays for.)

C · Files

It writes to its own folder, and to files you choose.

Everything the app writes on its own lives under %APPDATA%\Cadence Animator: settings.json, debug.log, an autosaves folder, a mesh and texture cache, and the presets you save. Anything else goes through a save dialog you open. The Studio plugin is one Lua file, CadenceBridge.lua, that you can read in full, copied into your Roblox plugins folder by your click.

D · No remote code

The interface can only run its own scripts.

Every window ships a Content-Security-Policy of script-src 'self': no inline script, no script from any server, ever. A compromised web page cannot become code inside Cadence, because the browser engine refuses it before it runs.

09 Questions

Before you download.

Is it safe?

Yes, and you do not have to take our word for it: the safety section links every claim to the file that makes it true. In short — the source is public (MIT), the app only connects to your own machine plus Roblox’s asset servers when you load an avatar and GitHub for update checks, it writes only inside its own %APPDATA% folder and to files you choose, its interface cannot run remote code, and you can hash your download on this page before running it.

The Windows warning you will see is about the missing code signature, not a detection. Here is what it looks like.

Why is it free?
Because the animator should be. Moon Animator went paid in 2023, and a lot of Roblox animators are thirteen with no card. The core of Cadence is MIT-licensed and stays that way; Pro exists to pay for the things that genuinely cost money — a code-signing certificate and the Studio bridge — not to hold features hostage.
Will it stay free?
Yes. It is MIT: even if the maintainer vanished tomorrow, anyone could build and ship it, and that is the point of the licence. Pro adds; it never removes. Nothing that is free today will move behind the key.
I don’t have a card.
You do not need one for Cadence — the free build is the whole animator. For Pro, a parent can buy it: it is a single one-time payment through Stripe Checkout, the key is emailed to whichever address is entered at checkout, and it works on any PC. If a friend or relative wants to gift it, they enter your email at checkout and the key comes to you.
What does Pro unlock exactly?

The procedural simulation pack — flocking, keep apart, liquid pressure, sub-emission, fire and smoke, clouds and the volume renderer — Roblox export of any procedural effect (baked recordings, flipbook sheets and .obj meshes), the Pro badge and priority updates. One key, tied to your email, every future Pro feature included.

It is a key, not a lock. The Pro code lives in the same public repository as everything else; the official build asks for a key before switching it on, and the MIT licence allows you to build it yourself without one. What you are paying for is the built, updated, soon-signed app — the same reason people pay for Aseprite or Krita on Steam when the source is free.

Can I use it commercially?
Yes. The animations and effects you make are yours, with no attribution required. The app itself is MIT-licensed, so a studio can use it, modify it and ship it; the only condition is keeping the licence notice with the code.
Do I still need Roblox Studio?
Yes, for two things: getting rigs out of your game and publishing the finished animation. You can animate entirely in Cadence — the built-in R6, R15, Rthro and Rthro Slender rigs need no Studio at all — but Studio is where the export lands and where Roblox’s own Animation Editor turns it into an asset ID.
Is there a macOS or Linux build?
Not today. The published builds are Windows x64 only. The app is Electron, so nothing about it is fundamentally Windows-bound, but no other platform has been built or tested and it would be wrong to imply otherwise.
Will it overwrite my Moon Animator work?
No. Cadence reads and writes the same AnimSaves folders Moon and Roblox’s Animation Editor use, and identifies rigs by a GUID attribute rather than by name, so it cannot mix up two rigs that share a name. Exports go to a name you choose.
How do updates work?
The installed build checks the project’s GitHub releases a few seconds after launch, and whenever you run Check for updates. If there is a newer version a chip appears in the title bar. Nothing downloads or installs until you click it, and a failed background check stays silent rather than interrupting you.
What actually gets sent anywhere?
Roblox’s own servers, for the things that need them: looking up an avatar, fetching a mesh, texture or model asset, and reading a published animation. The update check hits GitHub. The Studio bridge and the MCP server are both loopback-only. The phone companion is off unless you turn it on, and then it is token-gated over a temporary tunnel. There is no analytics or telemetry of any kind — the privacy page is ten lines.
Is it finished?
It is at 0.11.0 and used in real projects, with a 77-check smoke test run before each release. It is also below 1.0 and moving quickly — the changelog shows how quickly. The node editor inside VFX Studio is explicitly early. If something breaks, the app keeps a log next to its settings and the repository takes issues.
